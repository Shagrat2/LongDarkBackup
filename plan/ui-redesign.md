# План редизайна интерфейса LongDarkBackup

## Проблемы текущего интерфейса

1. **Светлая тема** — не соответствует стилистике The Long Dark
2. **3 уровня вложенных аккордеонов** (сохранение → день → запись) — скриншот доступен только после 3 кликов
3. **Фиксированная ширина 400px** — не адаптивно
4. **Сортировка по возрастанию** — старые сохранения сверху, нужно скроллить до новых
5. **Restore — текстовая ссылка** без подтверждения
6. **Нет информации о времени бэкапа** — видно только игровое время
7. **Все данные грузятся в одном Render()** — медленно при тысячах бэкапов

## Визуальный стиль The Long Dark

### Палитра

| Роль | Цвет | Hex |
|------|-------|-----|
| Фон основной | Тёмно-синий/чёрный | `#0a0e17` |
| Фон карточки | Тёмно-серый полупрозрачный | `rgba(20, 28, 40, 0.85)` |
| Фон карточки hover | Чуть светлее | `rgba(30, 42, 58, 0.9)` |
| Текст основной | Холодный белый | `#c8d6e5` |
| Текст приглушённый | Серо-голубой | `#5e6e82` |
| Акцент тёплый | Янтарный | `#d4a857` |
| Акцент холодный | Ледяной голубой | `#4fa4b8` |
| Опасность | Приглушённый красный | `#a04040` |
| Состояние хорошее | Приглушённый зелёный | `#4a8c5c` |
| Граница | Тонкая серая | `rgba(100, 120, 140, 0.3)` |

### Типографика

- **Заголовки**: `"Bebas Neue"` или `"Oswald"` (condensed sans-serif, uppercase) — напоминает шрифты в меню TLD
- **Текст**: `"Inter"` или системный `-apple-system, sans-serif`
- **Числа/статы**: `"JetBrains Mono"` или `monospace`

### Эффекты

- Лёгкий frost/blur на фоне карточек (`backdrop-filter: blur(10px)`)
- Тонкие бордеры 1px вместо теней
- Плавные transition 0.3s на hover
- Без скруглений или минимальные (2-4px) — TLD использует резкие формы

## Компоненты

### 1. Шапка (Header)

- Логотип/название слева: снежинка + "LONGDARK BACKUP" (uppercase, Bebas Neue)
- Справа: выпадающий селектор сохранения (если несколько персонажей)

### 2. Блок «Последнее сохранение» (HeroCard)

- Крупный скриншот слева (300x170px)
- Справа: регион, режим, дни выживания, condition bar, мир
- Кнопка "Восстановить" — янтарная, с иконкой ↻
- Выделен рамкой или фоном чуть светлее

### 3. Сетка карточек (SaveGrid)

- CSS Grid: `grid-template-columns: repeat(auto-fill, minmax(200px, 1fr))`
- Карточка: скриншот сверху, под ним — время бэкапа, дни выживания, полоска condition
- Hover: подсветка границы янтарным, лёгкий scale(1.02)
- Клик: открывает детальный просмотр

### 4. Разделители по датам

- Горизонтальная линия с датой слева и количеством бэкапов справа
- Дата в формате "19 февраля 2026"
- Сортировка: новые сверху

### 5. Condition Bar

- Горизонтальная полоска 100px x 6px
- Цвет: зелёный > 60%, янтарный 30-60%, красный < 30%
- Фон: `rgba(255,255,255,0.1)`

### 6. Кнопка «Восстановить»

- Фон: `#d4a857` (янтарный)
- Текст: тёмный `#0a0e17`
- Hover: `#e0b86a`
- Uppercase, letter-spacing: 1px
- Показывает модальный диалог подтверждения

## Изменения в файлах

### `web/style.css` — полная переработка

- Тёмная тема
- CSS Grid для сетки карточек
- Стили карточек, condition bar, кнопок
- Модальный диалог
- Адаптивность (mobile: 1 колонка, tablet: 2, desktop: 3-4)
- Подключение Google Fonts (Bebas Neue, Inter)

### `appList.go` — новая структура рендеринга

- Убрать 3-уровневые аккордеоны
- Сортировка: новые сохранения сверху (reverse sort)
- Первый элемент — HeroCard (последний бэкап крупно)
- Остальные — сетка карточек, сгруппированных по дате
- Клик по карточке → детальная страница (или модальное окно)

### `app.go` — новые маршруты

- `/` — главная с сеткой карточек
- `/save/{id}` — детальный просмотр одного бэкапа (API возвращает JSON)
- `/restore/{id}` — оставить как есть, но вызывать через JS fetch + confirm

### `restore.go` — подтверждение

- Убрать redirect, возвращать JSON-ответ `{"ok": true}`
- Фронтенд обрабатывает через fetch() и показывает результат

### Этап 1: CSS и визуальный стиль
