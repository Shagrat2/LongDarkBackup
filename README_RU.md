# LongDarkBackup
Автоматическое резервное копирование сохранений LongDark

## Использование
Программа проверяет файлы сохранений на наличие изменений каждые 5 секунд.
А если вдруг из-за угла выскочит волк и укусит вас. Вы можете откатить сохранение к предыдущему состоянию одной кнопкой.

## Установка
Скачайте последний релиз со страницы релизов, распакуйте его куда-нибудь на свой компьютер и запустите LongDarkBackup.exe.
