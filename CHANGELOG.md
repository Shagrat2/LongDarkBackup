# Changelog

Все заметные изменения проекта.

## [Unreleased]

### Added

- Настройка папки резервных копий через веб-страницу `/settings` и файл конфигурации; можно указать внешний диск, например `/Volumes/Disk/LongDarkBackup`.
- Файл конфигурации `LongDarkBackup/config.json` в системном каталоге конфигурации пользователя с атомарной записью.
- Скрипт сборки релизов для macOS (`.dmg`), Windows и Linux (Docker).
- Тесты конфигурации, настроек, восстановления и шаблонов страниц.

### Changed

- Приоритет путей: файл конфигурации → переменные окружения `LDB_DATA_DIR`/`LDB_BACKUP_DIR` → платформенные значения по умолчанию.
- Каталог резервных копий создаётся автоматически при запуске и при сохранении настроек, включая проверку прав на запись.
- Список бэкапов и страница сохранения больше не читают скриншоты без необходимости — отрисовка стала быстрее.
- Восстановление сейва выполняется атомарно через временный файл, чтобы сбой не испортил текущее сохранение.
- Переключатель языка вынесен в общий шаблон для всех HTML-страниц.

### Fixed

- Изменения больше не теряются, если папка бэкапов временно недоступна: неудачные файлы повторяются на следующем скане, успешные копии сохраняются.
- Устранён panic при восстановлении из отсутствующей папки бэкапа.
- POST-запросы настроек и восстановления защищены от межсайтовой отправки (same-origin).
- Исправлен запуск на чистой системе, когда папка резервных копий ещё не существует.
